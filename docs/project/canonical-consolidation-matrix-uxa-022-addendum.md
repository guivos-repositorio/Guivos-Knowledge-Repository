# Adendo da Matriz de Consolidação Canônica — Wireframe da Página Inicial Pública

## 1. Finalidade

Este adendo registra as decisões consolidadas da criação do wireframe gráfico vetorial da Página Inicial pública da Guivos.

Ele não substitui a Matriz de Consolidação Canônica central e não autoriza identidade visual, protótipo, desenvolvimento ou mudança empresarial.

## 2. Decisões consolidadas

| Elemento | Decisão | Resultado consolidado |
|---|---|---|
| Página Inicial pública | Materializar em wireframe | hierarquia funcional validada representada graficamente |
| Canal de referência | Usar web para computador | primeira referência criada para largura de computador |
| Dimensão | Usar como referência | 1.440 × 2.200 pixels, sem definir responsividade final |
| Cabeçalho | Orientar por intenção | funcionamento, exploração, ecossistema, instituições, sobre e entrada |
| Primeiro campo visual | Priorizar compreensão | propósito, descrição concreta, ações e garantia de ausência de coleta |
| Ação principal | Representar para visitante | `Iniciar minha jornada` |
| Exploração geral | Representar como alternativa | `Explorar sem personalização` |
| Coleta pública | Manter ausente | nenhum controle de texto pessoal, voz, câmera ou arquivo |
| Funcionamento | Representar em seis etapas | conhecer, decidir, contar, revisar, considerar e escolher |
| Caminhos de entrada | Separar visualmente | pessoal, exploração geral e institucional |
| Ecossistema | Agrupar por finalidade | produtos não aparecem como lista plana de igual prioridade |
| Guivos Journey, Mall, Travel e Media | Agrupar | jornada e possibilidades para pessoas |
| Guivos Business | Agrupar | Organizações, programas e Coletivos |
| Guivos Intelligence | Agrupar | compreensão e transparência, sem autoridade infalível |
| Guivos Ads | Agrupar | publicidade e patrocínio institucional identificados |
| Guivos Mall | Manter nome oficial | shopping do ecossistema |
| Guivos Ads | Manter nome oficial | solução de anúncios, publicidade e patrocínios |
| Possibilidades gerais | Representar de forma limitada | até três exemplos estruturais identificados e não personalizados |
| Conteúdo | Manter ilustrativo | não constitui dado, oferta, preço ou disponibilidade real |
| Confiança | Demonstrar por estrutura | ausência de coleta, transparência, controles e acessos institucionais |
| Referência móvel | Manter pendente | não iniciada |
| Responsividade | Manter pendente | dimensão de computador não define pontos de quebra ou comportamento final |
| Identidade visual | Manter pendente | nenhuma decisão de marca, cor, tipografia, imagem ou acabamento |
| Protótipo e testes | Manter pendentes | não iniciados |
| Engenharia de Produto | Manter pausada | antes de W0-01 |

## 3. Hierarquia materializada

```text
cabeçalho público orientado por intenção
→ identidade, propósito e descrição concreta da Guivos
→ ação principal e exploração sem personalização
→ garantia curta de ausência de coleta pública
→ explicação simples de como a Guivos atua
→ caminhos pessoal, geral e institucional
→ ecossistema organizado por finalidade
→ possibilidades gerais opcionais e identificadas
→ confiança, privacidade, transparência e controle
→ rodapé institucional
```

## 4. Estado empresarial preservado

- 18 de 18 decisões humanas concluídas;
- 9 candidatos em validação;
- 3 candidatos fundidos;
- 6 candidatos rejeitados;
- nenhum Resultado aprovado;
- nenhum código canônico criado;
- reaplicação dos quatro testes não iniciada;
- AQS-O01 e Capacidades Empresariais não iniciados.

## 5. Limites

Este adendo não:

- valida o início protegido da jornada;
- cria referência móvel;
- define texto final de marketing;
- cria identidade visual;
- cria protótipo navegável;
- executa testes com usuários;
- define tecnologia ou componentes;
- inicia Engenharia de Produto;
- inicia a reaplicação dos testes dos Resultados Empresariais.
