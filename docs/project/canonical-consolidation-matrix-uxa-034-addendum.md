# Adendo à Matriz de Consolidação Canônica — UXA-034

## 1. Finalidade

Este adendo registra a consolidação documental do wireframe móvel do início protegido da jornada.

Ele materializa o contrato funcional já validado pela UXA-023 sem criar decisão de tecnologia, identidade, autenticação, tratamento jurídico ou implementação.

## 2. Consolidação

| Tema | Autoridade preservada | Materialização no incremento |
|---|---|---|
| posição na jornada | UXA-003-A1; UXA-020; UXA-023 | Home → início protegido → compreensão inicial → Tela Hoje |
| explicação anterior ao acesso | UXA-020; UXA-023 | estado 1 antes da autenticação e da coleta |
| alternativas legítimas | UXA-020; UXA-023 | continuar, entender, voltar e explorar sem personalização |
| autenticação separada | UXA-023 | estado 2 declara que conta não autoriza processamento |
| modalidades equivalentes | UXA-023 | texto, voz, arquivo e perguntas opcionais |
| compartilhamento mínimo | UXA-011-A1; UXA-023 | estado 3 permite começar com uma frase |
| finalidade e privacidade | UXA-009; UXA-023 | finalidade atual e controles visíveis |
| revisão do conteúdo | UXA-023 | inventário de texto, respostas, voz e arquivos |
| autorização específica | UXA-011-A1; UXA-023 | escolhas separadas após revisão |
| gate de personalização | UXA-011-A1; UXA-020; UXA-023 | personalização bloqueada antes da compreensão revisada |
| pausa e exclusão | UXA-023 | ações distintas para pausar, salvar e excluir |
| proteção de terceiros | UXA-023 | alertas e limitação antes de voz e arquivos |
| acessibilidade funcional | UXA-005; UXA-009 | títulos, estados e alternativas textuais |

## 4. Estado resultante

O incremento propõe:

> **M7.35 — Wireframe Móvel do Início Protegido da Jornada Criado**

O conjunto ainda não foi funcionalmente validado como wireframe. O marco não equivale a protótipo, design, teste, autenticação, processamento ou desenvolvimento.

## 5. Limites de consolidação

Este adendo não:

- torna UXA-034 normativa;
- altera a autoridade funcional da UXA-023;
- valida o conjunto com usuários;
- define textos finais;
- define autenticação ou segurança técnica;
- define gravação, transcrição, upload ou IA;
- inicia Engenharia de Produto;
- altera Resultados Empresariais;
- cria Resultado canônico.
