# Adendo Canônico — UXA-042

## 1. Finalidade

Este adendo registra a consolidação proposta dos wireframes do cartão patrocinado e da explicação `Por que estou vendo isto?` do Opportunity Boost.

| Tema | Autoridade |

| validação do fluxo do anunciante | UXA-041 |
| cartão e explicação patrocinados | UXA-042 |

## 3. Resultado consolidado

A UXA-042 materializa seis referências de baixa fidelidade:

1. cartão patrocinado móvel;
2. explicação patrocinada móvel;
3. cartão patrocinado para computador;
4. explicação patrocinada para computador;
5. cartão móvel de Boost Social Financiado;
6. explicação móvel de Boost Social Financiado.

## 4. Regras demonstradas

- primeiro resultado orgânico preservado;
- inventário patrocinado separado;
- natureza comercial anterior ao conteúdo;
- anunciante ou financiador identificado;
- gratuidade ou preço visível;
- publicidade não apresentada como recomendação;
- critérios gerais utilizados explicados;
- relato, compreensão, Momento Atual e Próximo Passo excluídos;
- ausência de lista de visualizadores;
- ocultação, preferência, desativação, denúncia e contestação com escopos próprios;
- preferências reversíveis;
- oportunidade social permanece gratuita;
- financiador não recebe autoridade ou dados protegidos.
