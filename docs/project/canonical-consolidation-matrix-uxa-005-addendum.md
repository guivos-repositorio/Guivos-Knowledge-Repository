# Canonical Consolidation Matrix 2.3.0 — UXA-005 Initial Low-Fidelity Wireframes

## Decisões registradas

| Elemento | Decisão | Limite |
|---|---|---|
| programa de wireframes | criar em baixa fidelidade | não equivale a design system ou implementação |
| tela `Hoje` | materializar hipótese móvel | hierarquia e conteúdo permanecem em revisão |
| detalhe de oportunidade | materializar hipótese móvel | preço, relevância e elegibilidade não estão aprovados como layout final |
| cadastro pela Organização | materializar hipótese desktop | onze etapas permanecem sujeitas a simplificação |
| valores monetários | utilizar exemplos em pt-BR | não constituem preço comercial da Guivos |
| protótipo navegável | manter pendente | exige autorização posterior |
| Product Engineering | manter pausado | nenhum handoff ou código iniciado |
| `BUS-CAND-010` | manter pendente | nenhuma submissão, decisão ou fusão antecipada |

## Princípios preservados

- utilidade antes de frequência;
- clareza antes de persuasão;
- relevância antes de patrocínio;
- preço e custo total antes da confirmação;
- envio, ativação, apresentação e contratação como estados distintos;
- ausência legítima como estado válido;
- decisão final com o participante.
