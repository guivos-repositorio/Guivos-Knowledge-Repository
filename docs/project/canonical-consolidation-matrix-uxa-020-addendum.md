# Matriz de Consolidação Canônica — Adendo da Página Inicial da Guivos

## Registro

| Elemento | Decisão consolidada |
|---|---|
| primeira superfície pessoal | criar Página Inicial da Guivos anterior à Tela Hoje |
| nome de leitura | HOME da Guivos ou Página Inicial da Guivos |
| papel de impacto | apresentar propósito, início da jornada e amplitude do ecossistema |
| ação principal | convidar voluntariamente a iniciar a jornada |
| exploração sem jornada | manter disponível |
| relato do Momento Atual | permitir texto, voz, arquivos e perguntas progressivas |
| compartilhamento | manter mínimo, progressivo e justificável |
| compreensão inicial | apresentar antes de qualquer indicação pessoal |
| natureza das informações | distinguir confirmado, observado, externo autorizado, inferido, desconhecido e contestado |
| controles | permitir confirmar, corrigir, limitar, remover, rejeitar e recomeçar |
| personalização | bloquear antes de base suficiente e autorizada |
| base insuficiente | declarar ausência de compreensão segura |
| soluções apresentadas | Journey, Mall, Travel, Business, Media, Intelligence e Ads |
| conteúdo antes do gate | geral, institucional, editorial ou buscado explicitamente |
| publicidade | identificar e separar de relevância funcional |
| Tela Hoje | reposicionar como entrada recorrente depois da confirmação |
| navegação principal recorrente | manter Hoje, Jornada, Explorar, Mapa e Eu |
| acesso posterior à HOME | manter por marca ou menu institucional |
| wireframe | criar representação textual de baixa fidelidade |
| arquivo gráfico | manter pendente |
| protótipo e desenvolvimento | não iniciar |

## Cadeia funcional consolidada

```text
Página Inicial da Guivos
→ apresentação do propósito e do ecossistema
→ início voluntário da jornada
→ relato multimodal do Momento Atual
→ compreensão inicial apresentada
→ revisão, correção e autorização
→ Tela Hoje
```

## Fronteiras

A HOME:

- não é feed;
- não é catálogo infinito;
- não é questionário obrigatório;
- não afirma compreender a pessoa antes do relato;
- não transforma arquivo ou voz em autorização irrestrita;
- não reduz o ecossistema a recomendações comerciais;
- não obriga início da jornada para conhecer a Guivos.

A Tela Hoje:

- não perde a hierarquia funcional já validada;
- deixa de ser a apresentação institucional inicial;
- passa a utilizar contexto confirmado para apoiar continuidade e relevância;
- não precisa preencher todos os blocos.

## Próximo ato

A validação funcional da HOME, o arquivo gráfico, os estados de voz e arquivos e a primeira Tela Hoje após a transição dependem de autorização posterior.
