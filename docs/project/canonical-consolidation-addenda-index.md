# Índice dos Adendos da Matriz de Consolidação Canônica

## 1. Finalidade

Este índice torna rastreáveis os adendos posteriores ao checkpoint da Matriz de Consolidação Canônica central.

Ele não funde os adendos, não altera decisões anteriores e não declara que a matriz central foi recompilada.

## 2. Regra de precedência

```text
autoridade normativa de domínio
→ adendo especializado do pacote
→ Matriz de Consolidação Canônica central para decisões já consolidadas
→ este índice para descoberta e navegação
```

O índice não é fonte autônoma de decisão.

## 6. Estado de consolidação

| Camada | Estado |
|---|---|
| Matriz central | preservada no checkpoint vigente do arquivo central |
| adendos UXA-039 a UXA-070 | preservados como documentos especializados |
| índice de descoberta | criado por este documento |
| recompilação integral da matriz | não executada |
| UXA-071 | não iniciada |

## 7. Critério para consolidação futura

Uma edição consolidada futura deverá:

- declarar o intervalo de adendos absorvido;
- preservar decisões e proveniência;
- resolver conflitos explicitamente;
- atualizar versão e data da matriz central;
- manter os adendos como histórico rastreável;
- passar por validação mecânica e semântica;
- depender de autorização própria.
