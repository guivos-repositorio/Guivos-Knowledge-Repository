# Matriz de Consolidação Canônica — Adendo da Reformulação Funcional da Tela Hoje

## 1. Finalidade

Este adendo registra as decisões consolidadas pela primeira validação funcional da Tela Hoje.

## 2. Decisões consolidadas

| Elemento | Decisão | Consequência |
|---|---|---|
| Síntese do momento | Refinar | passa a ser condicional e é omitida quando repetir um único item ou não acrescentar compreensão |
| Atenção principal | Manter | somente um item ocupa o maior destaque |
| Múltiplos itens críticos | Refinar | o item prioritário permanece visível e os demais são reunidos na Central de Intervenções |
| Contexto de atuação | Refinar | seletor passa a utilizar `Agindo como` |
| Movimento atual | Manter | Próximo Passo permanece antes das oportunidades |
| Oportunidades | Refinar em wireframe | até dois cartões empilhados e em largura integral |
| Quantidade de oportunidades | Manter variável | nenhum cartão será criado apenas para preencher a tela |
| Coletivos e atividades | Refinar em wireframe | bloco aparece somente com utilidade temporal |
| Navegação pessoal | Manter | Hoje, Jornada, Explorar, Mapa e Eu |
| Protótipo navegável | Manter pendente | não iniciado |
| Design visual | Manter pendente | não iniciado |
| Testes de usabilidade | Manter pendentes | não iniciados |
| Engenharia de Produto | Manter pausada | nenhuma unidade de trabalho iniciada |

## 3. Estados não consolidados

Permanecem pendentes de desenho e decisão separados:

- estado totalmente vazio;
- múltiplos itens críticos;
- modo discreto;
- baixa conectividade;
- falha de fonte externa;
- contexto de Organização;
- contexto de Coletivo;
- texto ampliado e outras necessidades de acessibilidade.

## 4. Próximo ato

A próxima decisão deverá selecionar a validação do Detalhe de Oportunidade, a validação do Cadastro pela Organização ou um estado alternativo da Tela Hoje.
