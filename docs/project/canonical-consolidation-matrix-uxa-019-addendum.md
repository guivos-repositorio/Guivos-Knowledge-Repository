# Matriz de Consolidação Canônica — Adendo do Contrato Funcional das Relações entre Organizações e Coletivos

## 1. Finalidade

Este adendo preserva o detalhamento das decisões consolidadas para relações bilaterais entre Organizações e Coletivos.

## 2. Decisões

| Tema | Decisão consolidada | Consequência funcional |
|---|---|---|
| Natureza da relação | tornar explícita | apoio, patrocínio, serviço, operação, marca e dados não se confundem |
| Propriedade | proibir inferência | relação não transfere direção ou pertencimento |
| Consentimento | exigir bilateralmente | as duas autoridades aprovam o mesmo escopo |
| Aceite implícito | rejeitar | silêncio, presença e recurso recebido não ativam a relação |
| Autoridade | delimitar | unidade, papel, poderes, limites, prazo e revogação permanecem visíveis |
| Compromissos | tornar verificáveis | responsável, finalidade, prazo, evidência e alternativa são definidos |
| Recursos | tornar transparentes | origem, valor, finalidade, restrição, guarda e destino são registrados |
| Patrocínio | identificar e separar | investimento não aumenta relevância funcional |
| Dados | minimizar e governar | finalidade, acesso, retenção, correção, revogação e saída são definidos |
| Dados de membros | não transferir automaticamente | consentimento individual permanece necessário quando aplicável |
| Marca e comunicação | delimitar | canais, declarações, imagens, retirada e correção são governados |
| Autonomia do Coletivo | manter | apoio não controla propósito, pertencimento ou governança |
| Representação institucional | limitar | Coletivo não compromete a Organização fora do escopo |
| Influência e dependência | tornar visíveis | exclusividade, veto, controle editorial e conflito são declarados |
| Proteção | manter obrigatória | acessibilidade, denúncia, resposta urgente e não retaliação são preservadas |
| Ciclo de vida | governar | proposta, aprovação, atividade, revisão, pausa e encerramento são rastreáveis |
| Alteração material | exigir nova aprovação | finalidade, público, dados, recursos e autoridade não mudam unilateralmente |
| Avanço da relação | exigir evidência | duração, valor, reuniões e visibilidade não equivalem a avanço |
| Contestação | manter disponível | correção, divergência, denúncia e revisão possuem processo |
| Suspensão urgente | permitir proporcionalmente | risco material pode interromper o escopo durante análise |
| Encerramento | tornar responsável | dados, recursos, marcas, comunicação e obrigações remanescentes são definidos |

## 3. Cadeia funcional

```text
participantes distintos
→ finalidade compartilhada e limitada
→ consentimento bilateral
→ autoridade identificada
→ compromissos verificáveis
→ recursos e dados transparentes
→ autonomia protegida
→ acompanhamento e revisão
→ saída possível e responsável
```

## 4. Limites

Este adendo não constitui contrato jurídico, não define regras universais internacionais e não cria assinatura eletrônica, protótipo navegável, design visual, teste com usuários, especificação técnica ou desenvolvimento.

## 5. Ordem preservada

Após a integração e nova autorização, o retorno aos Resultados Empresariais e à capacidade de reinvestimento responsável permanece como próxima etapa.
