# Adendo Canônico — UXA-044

## 1. Finalidade

Este adendo registra a consolidação proposta dos wireframes dos estados patrocinados para Lista e Mapa do Opportunity Boost.

## 2. Autoridades preservadas

| Tema | Autoridade |
|---|---|
| contrato econômico do Boost | GEM-007-A1 |
| orçamento, preço e mensuração candidatos | GEM-010-A2 |
| contrato funcional da experiência | UXA-038 |
| validação funcional do contrato | UXA-039 |
| cartão e explicação patrocinados | UXA-042 |
| validação do cartão e da explicação | UXA-043 |
| estados patrocinados de Lista e Mapa | UXA-044 |

## 3. Resultado consolidado

A UXA-044 materializa quatro referências de baixa fidelidade:

1. Lista patrocinada móvel;
2. Lista patrocinada para computador;
3. Mapa patrocinado móvel;
4. Mapa patrocinado para computador.

## 4. Regras demonstradas

- uma única consulta territorial entre Lista e Mapa;
- localização opcional e região manual distinta da posição pessoal;
- primeiro resultado orgânico preservado;
- inventário pago separado da ordenação;
- marcador patrocinado textual e estruturalmente distinto;
- agrupamentos com contagens orgânicas e patrocinadas separadas;
- marcador pago sem sobreposição de oportunidade orgânica;
- filtro patrocinado reversível;
- baixa oferta orgânica reduz publicidade;
- proximidade não equivale a afinidade ou recomendação;
- explicação e controles equivalentes aos cartões patrocinados;
- ocultação sem redução do catálogo orgânico.
