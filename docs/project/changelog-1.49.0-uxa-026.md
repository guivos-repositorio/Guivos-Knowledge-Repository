# Histórico de Alterações 1.49.0 — Mapa com Localização Desativada

## 1. Escopo

Este incremento cria o primeiro estado alternativo gráfico do Mapa de Oportunidades para uso sem localização do dispositivo.

## 2. Principais alterações

- criação da UXA-026;
- criação do arquivo vetorial móvel de 390 por 844 pixels;
- região manual estabelecida como alternativa real;
- exploração geral sem personalização demonstrada;
- marcador de posição pessoal removido;
- busca, filtros, Mapa e Lista preservados;
- distância pessoal substituída por região ou origem informada;
- ativação de localização aproximada mantida opcional;
- rota condicionada à definição de origem válida;
- adendo canônico GKR-CANON-MATRIX-UXA-026 criado;
- marco M7.27 registrado;
- estado global, roadmap, marcos, programa de wireframes e navegação documental atualizados.

## 3. Resultado

O Mapa passa a possuir uma referência gráfica explícita para continuidade sem localização e sem personalização simulada.

## 4. Limites preservados

O incremento não executa teste de usabilidade, não cria geocodificação ou rota, não define fornecedor de mapas, não cria referência para computador, não inicia design visual, protótipo navegável ou Engenharia de Produto.

Nenhuma etapa posterior é iniciada automaticamente.
