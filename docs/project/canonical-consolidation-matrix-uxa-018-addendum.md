# Matriz de Consolidação Canônica — Adendo da Validação Funcional do Início do Coletivo

## 1. Finalidade

Este adendo preserva o detalhamento das decisões consolidadas na primeira validação funcional do Início do Coletivo.

## 2. Decisões

| Tema | Decisão consolidada | Consequência funcional |
|---|---|---|
| Propósito | posicionar antes da atividade | agenda e volume não definem o Coletivo |
| Pertencimento | separar de disponibilidade | ser membro não implica disponibilidade ou obrigação |
| Estado de participação | tornar explícito | observar, participar, pausar e sair permanecem legítimos |
| Necessidade principal | apresentar sem pressão | ausência de voluntários não gera culpa ou exposição |
| Convite | tornar recusável | convite não cria obrigação ou punição |
| Papel | exigir aceitação | responsabilidade somente existe após aceite explícito |
| Desistência | preservar | função aceita poderá ser devolvida por caminho compreensível |
| Ação compartilhada | subordinar ao propósito | atividade é meio, não finalidade isolada |
| Governança | separar funções | consulta, decisão, execução, moderação e revisão não se confundem |
| Votação | limitar | popularidade e maioria simples não são padrões universais |
| Relação de apoio | preservar autonomia | Organização apoiadora não assume direção automaticamente |
| Avanço coletivo | exigir evidência | propósito, mudança, período, contribuição e limitações são necessários |
| Ausência de evidência | declarar | nenhum progresso será simulado |
| Próximo Passo | impedir atribuição automática | pessoas somente assumem responsabilidades após aceitação |
| Métricas de atividade | limitar | membros, mensagens, reações e atividades não equivalem a evolução |

## 3. Hierarquia validada

```text
propósito, identidade e participação
→ momento coletivo e como foi compreendido
→ necessidade ou decisão que precisa de cuidado
→ ação compartilhada relacionada ao propósito
→ formas voluntárias de participar
→ decisões, papéis e governança
→ recursos, relações e autonomia
→ avanço coletivo e evidências
→ escolhas e Próximos Passos justificados
→ navegação do Coletivo
```

## 4. Limites

Este adendo não detalha integralmente as relações entre Organizações e Coletivos e não cria protótipo navegável, design visual final, teste com usuários, sistema universal de votação, modelo jurídico, especificação técnica ou desenvolvimento.

## 5. Ordem preservada

Após a integração, o detalhamento das relações entre Organizações e Coletivos permanece como próxima etapa. Resultados Empresariais continuam posteriores.
