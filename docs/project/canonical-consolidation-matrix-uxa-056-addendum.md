# Adendo à Matriz de Consolidação Canônica — UXA-056

## 1. Finalidade

Registrar a contribuição da UXA-056 para descoberta, presença pública e participação em Coletivos sem transformar o contrato funcional em wireframe, política normativa final, sistema de reputação, comunicação implementada ou desenvolvimento.

## 3. Distinções preservadas

- busca não é sugestão da Guivos;
- sugestão não é recomendação pessoal;
- recomendação não é publicidade;
- acompanhar não é participar;
- convite não é participação;
- presença em atividade não é pertencimento permanente;
- participante não é automaticamente colaborador, moderador ou autoridade;
- disponibilidade não é obrigação;
- seguidores não são participantes;
- participantes do Coletivo não são automaticamente vinculados à Organização apoiadora;
- quantidade não é qualidade, reputação ou avanço;
- saída voluntária não é remoção por moderação;
- suspensão preventiva não é culpa confirmada.

## 4. Estado arquitetural

A UXA-056 acrescenta contrato funcional e não altera a contagem de wireframes do repositório.

| contratos funcionais de descoberta e participação em Coletivos | 0 especializado | 1 |
| novos wireframes de Coletivos | 0 | 0 |
| protótipos e testes | 0 | 0 |

## 5. Fronteiras

O adendo não:

- cria interface final;
- materializa os 20 estados listados pela UXA-056;
- define avaliação ou reputação;
- define discussões, mensagens ou recomendações;
- cria tecnologia de busca, ranking ou recomendação;
- autoriza compartilhamento de dados;
- altera planos ou preços;
- inicia Engenharia de Produto.
