# Jornada Integrada do Coletivo

## 1. Papel

O Coletivo é ator coletivo com governança, responsáveis e participantes. Não deve ser antropomorfizado nem confundido com Organização.

## 2. Descoberta e participação

```text
HOME PÚBLICA O/C
→ DESCOBERTA
→ PERFIL PÚBLICO
→ REVISÃO
→ SOLICITAÇÃO
→ DECISÃO DO RESPONSÁVEL
→ PARTICIPAÇÃO
```

Participação exige vínculo e autoridade adequados. Solicitação, aprovação e acesso são estados distintos.

## 3. Experiência do responsável

```text
VISÃO GERAL
→ SOLICITAÇÕES
→ PARTICIPANTES E VÍNCULOS
→ COMUNICAÇÃO
→ ATIVIDADES / DECISÕES
→ PROTEÇÃO / MODERAÇÃO
→ RELAÇÕES INSTITUCIONAIS
```

A topologia autenticada é governada pelos Jobs/autoridades e pelas demais autoridades O/C correntes.

## 4. Domínios de Evolução

Domínios podem contextualizar finalidade, iniciativas e atividades do Coletivo. Eles não constituem score, maturidade moral ou diagnóstico do grupo.

## 5. Planos

Coletivo usa `Livre · Mobiliza · Impacta · Rede`.

Abrir Planos não altera vínculo, capacidade, consentimento ou participação.

## 6. Proteções

- autoridade do responsável proporcional ao papel;
- participação não concede acesso irrestrito;
- evento ou vínculo passado não cria autorização corrente;
- comunicação oficial não substitui consentimento;
- relevância e patrocínio não alteram governança.

## 7. Autoridades de prototipação

Usar os registries correntes e as autoridades autenticadas O/C vigentes. Nenhum artefato histórico define UI principal.

## 8. Estado

```text
→ CURRENT

AUTHENTICATED TOPOLOGY
→ CURRENT AUTHORITIES

HIGH-FIDELITY DESIGN
→ AUTHORIZED / NOT_STARTED

INTERACTIVE PROTOTYPE
→ NOT_AUTHORIZED

VISUAL MATERIALIZATION
→ DESIGN-OWNED

HISTORICAL UI
→ EXCLUDED
```
