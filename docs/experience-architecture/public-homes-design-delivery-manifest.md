# Homes Públicas — Manifesto Canônico de Fontes para Design

## 1. Finalidade

Este Manifesto define **o conjunto corrente de fontes que a designer e sistemas de IA podem consumir** para desenvolver as oito Homes públicas.

```text

→ CURRENT MAIN

HISTORICAL CONSTRUCTION
→ GIT

SNAPSHOT / CANDIDATE
→ NOT OPERATIONAL AUTHORITY

EXTERNAL EXPORT
→ OPTIONAL DERIVED ARTIFACT
```
