# Homes Públicas — Fluxo Operacional Corrente de Design

## 1. Fluxo

```text
CURRENT MAIN
→ MANIFEST
→ COMMON AUTHORITIES
→ ONE HOME AT A TIME
→ HOME MASTER + SPECIFIC SOURCES
→ HUMAN UNDERSTANDING
→ DESIGN CREATION
→ OPTIONAL AI
→ AUTOAUDIT
→ HUMAN REVIEW
```

## 2. Gate de início

Iniciar quando:

- o Manifesto aponta fontes correntes;
- o Master da Home está corrente;
- não existe finding material aberto;
- o Design Production Release está concedido.

Snapshot externo não é requisito.

## 3. Compreensão humana

Antes de desenhar, compreender:

- papel da Home;
- tese;
- pergunta-mãe;
- movimentos;
- público;
- participantes e produtos;
- provas e dados;
- guardrails;
- perguntas em aberto.

## 4. Criação

A designer decide forma visual e pode reorganizar movimentos em seções, componentes e interações compatíveis com a progressão de significado.

## 5. Uso opcional de IA

IA pode ser usada em qualquer etapa criativa, desde que receba somente as fontes correntes da Home e respeite o contrato de classificação.

## 6. Autoaudit

Verificar:

- nenhum movimento perdeu função;
- nenhum produto virou participante;
- nenhuma oportunidade virou possibilidade por simplificação;
- nenhuma evidência foi inventada;
- nenhuma hipótese virou claim;
- a navegação não promete destino inexistente;
- visual não cria nova autoridade.

## 7. Entrega e revisão

A entrega deve permitir rastrear decisões materiais às fontes correntes.

```text
SNAPSHOT
→ OPTIONAL EXPORT ONLY

FINAL ACCEPTANCE
→ HUMAN

IMPLEMENTATION
→ SEPARATE

PRODUCT ENGINEERING
→ NOT RELEASED
```
