# Home Pública — Guivos Media — Documento Mestre

## Finalidade

Este documento governa exclusivamente a **Home Pública do Guivos Media — v1** e serve como referência canônica de handoff para Product Design, UX, UI, Content Design e implementação futura.

A Home do Media compartilha os fundamentos da marca Guivos, mas possui função, narrativa, ritmo e expressão editorial próprios. Ela não é adaptação de outra Home do ecossistema.

> **Este documento especifica a Home v1 do Guivos Media. Ele não redefine nem esgota o escopo integral do produto estabelecido em `GPA-005`.**

A materialização visual posterior deve preservar os contratos aqui estabelecidos. Este documento não contém protótipo visual nem UI final.
