# Homes Públicas — Autorização Corrente de Produção de Design

## 1. Decisão

```text
DESIGN PRODUCTION RELEASE
→ GRANTED

TARGET
→ 8 PUBLIC HOMES

SOURCE OF TRUTH
→ CURRENT MAIN + CURRENT MANIFEST

DESIGNER
→ CREATIVE AUTHOR

AI
→ OPTIONAL / DESIGNER-CONTROLLED

GKR-CREATED FIGMA
→ NONE
```

A designer está autorizada a produzir as oito Homes públicas com base nas autoridades correntes do GKR.

## 2. Escopo

A autorização cobre criação e refinamento de:

- arquitetura visual;
- wireframes;
- UI;
- responsividade;
- motion e interação;
- protótipos;
- conteúdo candidato necessário para avaliar a experiência.

## 3. Limites

A autorização não:

- congela identidade visual;
- cria fatos comerciais;
- altera produto;
- altera autoridade funcional;
- libera implementação;
- libera publicação;
- libera Product Engineering;
- autoriza experiências autenticadas fora de seus gates próprios.

## 4. Aceite

```text
DESIGN OUTPUT
→ AUTHORIZED

FINAL DESIGN ACCEPTANCE
→ HUMAN / SEPARATE

IMPLEMENTATION
→ SEPARATE GOVERNED ACT
```
